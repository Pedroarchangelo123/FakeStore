# FakeStore API Product List

Este projeto é uma aplicação simples que consome a FakeStore API para exibir uma lista de produtos. A aplicação foi desenvolvida usando **React** e utiliza a **FakeStore API** para buscar informações sobre os produtos, como título, descrição, preço e imagem.

## Funcionalidades

- Exibição de uma lista de produtos com título, descrição, preço e imagem.
- Cada produto é mostrado em um card com informações detalhadas.
- Interface limpa e simples utilizando o estilo baseado na fonte **Josefin Sans**.

## Tecnologias Utilizadas

- **React**: Biblioteca JavaScript para a construção da interface de usuário.
- **Axios**: Biblioteca para realizar requisições HTTP.
- **CSS**: Para o estilo e formatação da aplicação.
- **FakeStore API**: API de demonstração para listar produtos.
